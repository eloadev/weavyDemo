# ELOA Dev Team — Weavy

Este repositorio contiene el código fuente y los recursos de Weavy, desarrollado por el ELOA Dev Team (Eat Logic Output Art), un grupo de desarrolladores universitarios de Hermosillo, Sonora, México.

🔗 **Ver y Jugar en línea:** [https://eloadev.github.io/proyects/Weavy/inicioWeavy/](https://eloadev.github.io/proyects/Weavy/inicioWeavy/)

## Herramientas 
Motor de JuegoUnity, C#Renderizado / UIUniversal Render Pipeline (URP), TextMeshProDiseño y Clip Studio Paint, Unity Version Control y GitHub

## Descripción del Proyecto
Proyecto sobre la concientización sobre la contaminazión en los mares y la sedentarismo de los niños gracias a los juegos hoy en día por lo que se presento en el Rally del Niño Cientifico 2026 con un motion tracking como modo de juego.

## Cómo Ejecutar el Proyecto Localmente

Sigue estos pasos para clonar y abrir el proyecto en tu computadora:
- Clona el repositorio:Bashgit clone https://github.com/eloadev/weavyDemo.git
- Abre Unity Hub y selecciona Add project from disk.
- Selecciona la carpeta raíz del proyecto clonado.
- Asegúrate de tener instalada la versión compatible de Unity y abre la escena principal en la carpeta Scenes/.
